# 0.1.2 发布与升级验证

[0.1.2 已发布](https://github.com/IT-coder-Yy/SuperTravelAgent/releases/tag/v0.1.2)，源码提交 `3ee0ac6b515c12a651ac65cb95f6dae07d1495b6`。本版本先用于本机开发，默认工具地址为 `http://127.0.0.1:8080`，尚未部署公共云服务。

## 已完成

- 设置中的“工具服务地址”可修改、保存并立即生效，重启后恢复。仅保存地址到当前数据目录的 `tools.json`，旧配置留在 `.previous`；服务离线不阻止编辑地址。
- 地址只接受无凭据、无查询参数/片段的 HTTPS 或回环 HTTP。切换地址会停止旧任务，迟到结果不能覆盖会话。
- 工具密钥只在独立工具服务进程中使用，客户端仍只填写模型 URL、model 和 Key。复用已有官方 MCP/API 适配器，不新增数据库、账号或框架。
- 本机模式发布不要求 CI 运行工具服务；显式 HTTPS 模式仍验证服务目录。安装包和源码不含共享密钥。
- 更新清单与 GitHub Release 使用同一份发布说明，下载仍执行签名校验，镜像失败可回官方源。

- 四架构均通过原生签名更新、坏包/下载中断拒绝和本地 JSON 保留。Windows 额外验证 NSIS 安装后的完整候选主程序/后端哈希；macOS/Linux 验证原生启动和退出清理。
- [发布产物记录](v0.1.2-release-validation.json)：12 个公开资产均已实际下载，逐个核对 SHA-256、大小与校验清单；公网 `latest.json` 为 0.1.2，更新说明与 Release 正文一致。

## 使用方式与边界

开发者按[工具服务说明](../deploy/shared-tools/README.md)配置四项服务凭据，运行 `npm run tools:dev`。客户端默认连接同机 8080 端口，也可在设置中改为其他回环端口；以后上线服务时改为 HTTPS 地址。

工具服务不会随安装包自动启动。服务未运行时，普通模型聊天和本地历史仍可使用，依赖地图/检索的任务会提示连接错误。当前没有公共云服务；macOS 安装包未做 Apple 公证。macOS/Linux 的更新验证来自原生 CI，并非人工 GUI 验收。

默认地址调整前的历史证据仍保留在 [M4 早期原生验证](m4-native-validation.json) 和 [进程内 HTTP 联调](shared-tools-live-validation.json)，不作为本次正式发布或真实 Windows GUI 升级的替代证据。
