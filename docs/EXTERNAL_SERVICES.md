# 外部服务接入

用户只填写模型 URL、模型名、API Key。地图与检索连接、服务凭据、额度由开发者统一维护，不增加用户工具密钥表单。

0.1.2 先用于本机开发，安装包默认通过 `http://127.0.0.1:8080` 的独立工具服务访问各家现有 MCP/API。开发者运行 `npm run tools:dev`，工具凭据只在该服务环境中配置；客户端设置提供“工具服务地址”，不增加工具密钥字段。模型请求和整份本地会话不经过工具服务。

后续上线 HTTPS 服务后，可直接在客户端设置里修改地址。地址保存至当前数据目录的 `tools.json`，立即生效并在重启后恢复；更换地址会停止旧任务。开发模式仍兼容本机直连。启动及部署方式见 [服务说明](../deploy/shared-tools/README.md)，发布进度见 [0.1.2 发布检查](M4.md)。

## 开发配置

在启动 `npm run dev` 的进程中显式设置 `STA_DEV_ENV_FILE`，指向开发者自己的环境文件。启动脚本只读取以下字段并传入本机 Python 内存，不复制旧文件，不传给浏览器，也不写入会话 JSON：

- 模型：`SAGE_BASE_URL`、`SAGE_MODEL_NAME`、`SAGE_API_KEY`。
- 外部服务：`AMAP_MAPS_API_KEY`、`BAIDU_MAP_API_KEY`、`TAVILY_API_KEY`、`SERPER_API_KEY`。

工具字段也可通过本机开发或服务端 Python 进程的同名环境变量配置。缺少某一项只影响对应服务，不阻止模型聊天或其他工具。`npm run tools:dev` 从 `STA_DEV_ENV_FILE` 只加载四项工具凭据，不加载模型配置；模型与工具密钥不写入会话 JSON。

连接优先级为已保存的工具地址 → 显式 `STA_MCP_URL` → `STA_SHARED_TOOLS_URL` → 有工具凭据时的开发直连 → 默认回环地址。安装包默认内置回环地址；构建变量 `STA_SHARED_TOOLS_URL` 可覆盖这个默认值，用户保存的地址优先。

地址只允许无凭据、无查询参数/片段的 HTTPS 或回环 HTTP。默认本机模式发布不要求 CI 运行工具服务；显式 HTTPS 模式仍检查五个服务条目配置和至少一个可用地点工具。只有工具名称和参数发往工具服务，不发送模型 Key、本地访问令牌或整份会话。

官方地址在后端固定，防止误配置把凭据发送到无关域名。高德使用 `key` 参数，百度使用 `ak` 参数，Tavily 使用 `Authorization: Bearer`，Serper 使用 `X-API-KEY`。凭据与基础 URL 分开传入传输层；拒绝重定向，日志和返回数据会遮盖密钥及其 URL 编码。

## 状态与额度

设置页初次打开读取服务内存状态，不自动查询地图/检索上游。共享服务的公共状态不展示其他用户最近的调用，客户端单独记录自己的最近调用。点击“检查工具服务”才读取工具目录；共享目录缓存五分钟，Serper 与小红书目录由现有适配器提供，目录注册不会冒充真实 API 已验证。

“已配置”“连接情况”“最近调用”分别记录。额度不足保留配置与工具，不自动重试这次失败，也不假定所有供应商都在同一天重置额度。额度恢复后重新发起需求即可，无需改接入代码。某家暂时不可连接时，其他服务仍能返回工具列表。

## 发布边界

0.1.2 的本机开发方式不依赖公网部署，也不提供已经上线的公共工具服务。工具服务需开发者单独启动；未启动时，模型普通聊天和本地历史仍可使用，需要工具的需求会报告连接错误。公开源码、安装包和服务镜像不包含共享密钥。

共享服务默认单进程、单副本，每 IP 每分钟 20 次调用、全局 UTC 日上限 1000 次、最多并发 4 次；失败和无效调用也计数。超限不访问上游。内存限额重启重置，扩容前需要共享限额存储；正式运营须同时设置供应商账户额度上限。

## 验证与来源

[真实调用记录](external-services-validation.json)：生产 `ExternalTools` 发现 26 个只读工具；百度、Serper、小红书公开索引各最多查询一次，没有模型调用或失败重试。257 条内存日志扫描未发现原始或 URL 编码密钥，原日志及完整搜索结果均未保存。

[本机独立服务记录](shared-tools-local-validation.json)：没有工具凭据的客户端通过真实回环 HTTP 发现 26 个工具，百度地点查询返回 10 个有效地点；不是进程内模拟，也不表示公网部署完成。

接入方式依据：[高德官方文档](https://lbs.amap.com/api/mcp-server/gettingstarted)、[百度官方 MCP](https://github.com/baidu-maps/mcp/blob/main/README_zh.md)、[Tavily 官方 MCP 文档](https://docs.tavily.com/documentation/mcp)、[Serper 官方服务](https://serper.dev/)。不把工具发现成功当成所有业务接口均有额度。
