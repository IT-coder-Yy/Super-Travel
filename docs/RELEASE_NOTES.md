## SuperTravel 0.1.2

本版本先用于本机开发，未提供已上线的公共工具服务。客户端默认连接 `http://127.0.0.1:8080`，开发者需另行运行 `npm run tools:dev` 并在服务环境中配置工具凭据；客户端设置可修改服务地址。

- 双 Agent 负责沟通、澄清、规划与工具执行，支持取消、进度恢复及执行失败后的重规划。
- 支持国内单目的地 1～7 天真实行程、地图地点展示、聊天修改及手动编辑。
- 修改先保存为草稿，确认后应用；会话和行程使用本地 JSON，支持重启恢复与上一版恢复。
- 用户只需配置模型地址、模型名和 API Key；地图与搜索通过工具服务访问，客户端不填写工具 Key，工具密钥不进入安装包。工具服务未启动时相关功能不可用；工具可用性仍受供应商额度和网络影响。后续可在设置中改用开发者提供的 HTTPS 服务地址。
- 模型 Key 使用系统凭据库保存。保留 C2 图标、约 3 秒开场及任意键跳过。
- 提供 Windows x64、macOS Apple Silicon/Intel、Linux x64 安装包与签名更新。

地图用于地点展示，不提供精确导航或营业、票价、预约保证。小红书能力为公开索引搜索，不是官方登录后笔记接口。macOS 安装包尚未 Apple 公证，首次打开可能需要在系统设置中允许。
