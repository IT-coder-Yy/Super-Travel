## SuperTravel 0.1.4

本版本包含第二、第三阶段的核心体验完善，仍使用本机工具服务。客户端默认连接 `http://127.0.0.1:8080`；开发者需另行运行 `npm run tools:dev` 并在服务端配置工具凭据。公共工具服务尚未上线，客户端设置可修改服务地址。

- 真实地点新增、替换、确认删除与跨日移动；候选池可加入正式行程。新增同日和跨日拖拽：松开后确认位置、时间并保存草稿，再应用为正式行程；保留按钮和键盘操作。
- 常用旅行偏好支持预算、节奏、饮食和同行方式；本次明确要求优先。聊天续改保留稳定活动 ID、用户备注、费用、收藏和候选池。
- 公交接驳展示百度/高德首方案的线路、上下车站、换乘次数及参考总票价；公交或驾车接驳展示同次查询的出租车估算、时段和备注。有效零金额原样展示，并注明“仅供参考，以实际结果为准”；交通参考价不计入活动费用小计。
- Markdown/PDF 导出仅包含已确认的正式行程，支持罕字和 emoji，字体及表情资源随安装包提供。未应用草稿与候选池不会混入正式导出。
- 修复含 emoji 或扩展区汉字的交通文本在长度上限处无法重新加载会话的问题，前后端统一按 Unicode 码点计数；旧 JSON 无需迁移。
- 高德 MCP 工具目录保留完整首次查询超时窗口，瞬态失败后仅用剩余预算重试一次；失败仍保留基础地图接口和明确状态，业务调用不因此自动重试。
- 保留双 Agent、草稿确认、本地 JSON 保存与恢复、图标和开场动画、系统凭据库及签名更新。用户仅配置模型 URL、模型名和 Key；共享工具密钥不进入安装包。
- 提供 Windows x64、macOS Apple Silicon/Intel、Linux x64 安装包与签名更新。新资产采用统一平台文件名，更新清单平台标识及已发布历史资产保持兼容。

地图、票价和出租车金额用于参考，不保证出行当天的路况、营业或预约结果。真实工具可用性受供应商额度与网络影响。小红书能力为公开索引搜索，不是官方登录后的笔记接口。

macOS 安装包采用 ad-hoc 签名，尚未 Apple 公证，首次打开可能需要在系统设置中允许。Linux 需具备中文字体，精简 Ubuntu/Debian 可安装 `fonts-noto-cjk`。
